Live: https://nanobotco.github.io/ferc-plan/ (noindex)

- Words: `tools/build.py` (WORDS, English and German side by side). Edit, then `python3 tools/build.py`.
- Pages: `docs/index.html`, `docs/de/`, `docs/board/`, `docs/de/board/`.
- Look: `docs/style.css`, `docs/app.js` (text size, light or dark, read aloud).
- Source of the plan: Marcus's "FERC: What We Could Offer" (22 Oct) and Eveline's written answers of 22 Oct, which stay off this site.
- Photos: Wikimedia Commons, credits in the footer.
